# SmartOverlay

Professional Live Overlay + Remote Controller system.

## Phase 1
- GitHub project foundation
- Controller and Overlay pages
- Responsive desktop/tablet/mobile UI foundation
- Modular CSS/JavaScript architecture
- Firebase configuration placeholder
- Basic local canvas/box interaction
- Scene, question, quiz, timer, PDF and media engine foundations

## Planned
1. Foundation
2. Controller Desk
3. Free Canvas
4. Graphics & Text
5. Media
6. Question Bank
7. Quiz/Test
8. PDF Studio
9. Scene System
10. Final optimization and production testing

## Firebase
Create a Firebase Web App and replace the placeholders in `js/firebase.js`. Do not commit service-account credentials or other private secrets.

## Run
The project is static HTML/CSS/JS and can be hosted with Firebase Hosting or another static host.
